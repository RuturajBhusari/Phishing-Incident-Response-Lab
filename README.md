🛡️ Phishing Incident Response Lab

📌 Overview

This repository contains six simulated phishing incident investigations performed in a SOC (Security Operations Center) lab environment.

The objective of this project is to demonstrate the complete phishing investigation lifecycle, including email analysis, IOC extraction, threat hunting, Splunk log analysis, incident validation, containment, and remediation.


🎯 Skills Demonstrated

- Email Header Analysis
- Phishing Investigation
- IOC Extraction
- Splunk Log Analysis
- Email Gateway Analysis
- Proxy Log Investigation
- Threat Hunting
- Malware Analysis
- Hash Verification
- Incident Response
- Root Cause Analysis
- Containment & Remediation
- Security Awareness Recommendations
